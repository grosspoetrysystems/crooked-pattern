# Crooked Pattern: check AI-agent readiness

Crooked Pattern is a CLI and MCP server for checking the agent-facing signals
of a website and repository. Its Agentic Readiness Score (ARS), maturity gates,
and evidence-backed reports help you find blockers and catch regressions.
It does not predict search rankings, AI recommendations, or agent task success.
