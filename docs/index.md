# crooked-pattern

Agentic Readiness Score (ARS): a deterministic 0–100 score and T0–T5 maturity
tier for how ready a website and repository are for AI agents.

Installed packages include these docs for offline use. Run `ars docs` for the
index, `ars docs scan.md` to read a page, or `ars docs --graph` for links and
navigation. `ars docs --revision` prints the bundled graph's SHA-256 digest.
